## Version 1.6.0 (2026-06-06)

- Added syntax highlighting for many more languages: TypeScript, JavaScript, CSS, HTML, JSON, YAML, XML, Rust, Go, Java, PHP, Shell, SQL, Ruby
- enum members neutral black; gold reserved for constants/macros
- Rust: self/Self pink, primitive types purple (like C int), macro pink
- Java import/package paths black like Python; PHP <?php green
- TOML supported when a TOML extension (e.g. Even Better TOML) is installed
- Added screenshot-based preview tooling (scripts/preview.ps1, samples/)

## Version 1.6.1 (2026-10-16)

- Fixed editor UI colours that fell back to VS Code's default blue/green/red: focus borders, search option toggles, quick-pick group labels, peek view, diff line backgrounds
- Files with errors in the explorer are now pink instead of blue
- Explorer indent guides grey instead of black; active line number pink
- Sidebar section headers (folder name, Outline, Timeline) were white on white, now dark grey; peek editor background no longer blue-tinted
- Current find match now has a pink border; status bar items show a hover background
